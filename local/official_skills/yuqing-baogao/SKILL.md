# 报告生成（周报 / 月报 / 季度报 / 年报）

当用户的请求匹配本 Skill 的能力时启用。你是通用智能体上的专项能力，不是独立专家 Bot：完成任务后仍保持通用助手身份。

本 Skill 产出对客 / 行内 **Word 周期性监测报告**。  
**入口统一、模板分类型**：先判定报告类型，再**只**按该类型专属章节骨架撰写。  
**禁止**把四种报告当成「同一年报模板做加减」混用；月报尤其不得套用周/季/年的四章结构。

> 不要与「数据处理」(shuju-chuli) 混淆：本 Skill 交付 `.docx` 报告，不是打标 Excel。

---

## 启用约束（最高优先级）

1. **必须**确认报告类型为：**周报 / 月报 / 季度报 / 年报** 之一（未指定则先问；口语「季报」=季度报）。半年报按年报骨架、风险提示 **5** 条、period_label 为上/下半年。
2. **必须**确认：监测主体（机构名）、起止日期（或可推断的周期）。
3. **必须**有数据来源：已清洗/已标注明细，或工作区内可统计舆情明细。无数据则请用户补材料；缺打标可建议先 `shuju-chuli`。
4. **最终交付物必须是 `.docx`**，并用 `send_file_to_user` 发送；聊天给指标摘要，附件不能替代章节正文。
5. **禁止编造**条数、占比、媒体名、标题、事件、处置量；数字只能来自明细统计。缺字段则降级并写明。
6. 封面/表头「监测周期」与正文实际统计周期不一致时，**如实标注**，不得篡改原始监测数据。

从明细表统计；时间落在 `[period_start, period_end]`。各类型对情感命名、是否做日走势/类别等**以专属模板为准**。

**无处置字段或处置量为 0**：不要写「处置 0 条 / 处置率 0% / 应对不力」；策略段只给应对思路。

# 周报模板

**适用**：周报。对齐 aibank 短周期监测报告（概况 + 正面 + 敏感）。

## 口径
- 情感四分：**正面 / 中性 / 敏感** + **消费者网络匿名投诉**（互斥，合计=总量）。「负面」写作 **敏感**。投诉优先：信息分类/备注为「客户投诉」计入 complaint，不计入其余三类。
- 风险等级（按敏感占比）：≥20% 高；≥10% 中；否则 低。
- TOP N = **5**（正面/敏感热点话题、媒体平台各一份）。
- **不做**月度信息对比；**不写**风险提示章（除非用户明确要求）。

## 章节骨架
Word：**封面 → 目录 → 正文章节 →（可选）图表分析**。正文仿宋/宋体，标题黑体，主色深蓝。

### 封面
报告标题、监测主体、周期起止（「X年X月X日」）、成文日期。

### 一、本周舆情信息概况
1. **信息属性分析**：总量与四分占比 + 风险等级 + 属性分布图  
2. **信息来源分析**：渠道数据段 + 点评（集中度、短板建议；勿逐条复读全部数字）+ 来源图  

### 二、正面信息分析
1. **正面亮点**：条数、占比、热点方向（热词须来自话题标题）+ TOP 表（序号 / 热门标题 / 重点媒体 / 相关传播量）  
2. **正面媒体平台**：平台数、TOP 占比、榜首样本标题 + TOP 图  

### 三、敏感信息分析
1. **敏感概述** +（有处置时）处置成效句 + 敏感 TOP 表  
2. **敏感平台分析**：榜首平台传播机理与治理建议（可 250–350 字）  
3. **应对策略**：汇报/举报/投诉/媒体沟通/引导等；无处置数据时禁止评价「应对是否到位」

### 叙述示例（概况）
> {年}年本周（{起}-{止}），共监测到{机构}有效信息{total}条（篇），其中正面信息{pos}条，占{pos_pct}%；中性信息{neu}条，占{neu_pct}%；敏感信息{sen}条，占{sen_pct}%；消费者网络匿名投诉类信息{comp}条，占{comp_pct}%。根据舆情属性分布情况看，{机构}舆情风险等级：{level}。

# 月报模板

**适用**：月报。对齐行内月报规范（参考顺德农商行舆情月报结构，主体名用用户给定机构，勿写死某一家）。

## 口径
- 情感对外写作：**正面 / 中性 / 负面**（明细「敏感」→ 报告「负面」）。投诉类按明细归入对应情感或单独说明，**不得**虚构条数。
- 须能统计：**按日声量**（走势峰/次峰）、全量来源、**正面子集**的来源与信息类别、负面子集来源与焦点事件。
- 数字必须与数据表完全一致（条数、占比、传播量、时间区间）。

## 版式与出图
- 全文字体**微软雅黑**，字号**小四**，行距**固定值 28**。
- **默认只出文字**（计算准确即可）；用户明确要求配图时再出：走势用折线，性质/来源/类别用饼图。未配图时不要在正文写「见图 X」。

## 章节骨架（固定结构，按序输出）

### 一、我行舆情概况

#### 1、信息走势分析
根据数据表整理当月日声量走势；写出监测周期、有效信息总量（含原创和转发）、走势形态、**最高峰日**与**次高峰日**的信息量及主要内容事由。示例格式：

> 2026年8月份（8月1日至8月31日），共监测到{机构}有效信息4676条（含原创和转发）。从信息声量走势图看，本月数据呈现波动走势。其中，8月18日达到本月信息传播最高峰，信息量达343条，内容主要围绕……。8月4日出现次高峰，信息量327条，主要因……。

#### 2、信息性质分析
正面 / 中性 / 负面条数与占比 + 一两句环境总评。示例格式：

> 本月，共监测到{机构}有效信息4136条（含原创和转发），其中正面信息233条，占本月信息总量的比重为5.63%；中性信息3895条，占94.17%；负面信息8条，占0.19%。整体来看，本月我行舆情环境平稳可控，中性信息占据绝对主流，正面信息占比稳定，负面信息数量极少，未出现大规模负面舆情事件。

#### 3、信息来源分析
全量信息按渠道、数量由多到少；可点出头部渠道合计占比。示例格式：

> 本月{机构}信息中，来自网站1476条，占比为35.69%；微信1249条，占比为30.20%；……整体来看，网站、微信、客户端三大渠道合计占比超过九成，是本月我行舆情信息的主要来源。

（以上概况三段严格按照数据表计算撰写。）

### 二、我行正面舆情

#### 1、信息来源分析
**仅统计正面信息**的渠道分布（勿用全量来源冒充）。示例：

> 本月，我行233条正面信息中，来自微信的信息最多，共计105条，占比为45.06%；其次为客户端……正面信息主要来源于微信及客户端渠道，二者合计占比接近九成。

#### 2、信息类别分析
按数据表中正面信息的**信息分类**汇总（条数、占比、各类代表内容方向，事由须来自明细）。示例类别：产品创新、社会责任、市场活动、业绩报告、战略发展、荣誉奖项等——**以表内实际分类名为准**。

#### 3、主要正面信息影响力 TOP 表
表格列：**序号 | 时间 | 新闻标题 | 内容摘要 | 报道媒体 | 传播量（条） | 信息类型**。  
挑选标准：主体相关；优选高权重媒体与传播量大的内容。

### 三、我行负面舆情

#### 1、信息来源分析
仅负面信息的渠道分布 + 主要平台点名（须来自明细）。

#### 2、主要负面信息内容分析
归纳本月负面焦点（监管处罚、经营业绩、服务投诉等），可写「X 则（共 Y 条）」若表支持事件归并；传播态势与风险是否可控须有数据依据。

#### 3、主要负面舆情应对建议
挑选本月 **1–2 项**较重要负面（传播量大或媒体级别高）写应对建议；无突出舆情则写整体建议。示例句式：「一是建议针对……；二是针对……」。

### 四、同业负面
**空着不写**（除非用户明确提供同业材料并要求撰写）。

### 五、下月风险提示
根据本月负面舆情撰写：事件或背景概述 + 建议。

### 附件（可选占位）
如「下属/关联机构舆情概况」等附件位：**用户未要求则空着不写**。

# 季度报模板

### 三、敏感信息分析

## 章节骨架
